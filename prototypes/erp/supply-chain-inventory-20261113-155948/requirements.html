需求文档 V1.0更新：2026-11-12需求评审稿适用：产品 · 业务 · 设计 · 研发 · 测试

本版按最终收货仓库统计五个节点，补齐各节点预计到货。用户已明确的规则直接纳入正文；时效配置、去重、异常及权限边界集中列在开放问题中，不以演示数据代替业务确认。

01 背景、目标与范围

在一个报表中查看申购、采购、中转、调拨在途和海外仓库存。数量必须能追溯到来源单据，并展示各节点预计到货时间，便于计划、采购和仓储核对补货进度。

事项本版要求确认状态
统计粒度仓库 + 产品组 / SKU。仓库表示最终收货仓库；移除站点筛选、展示及导出维度。用户确认
界面调整“海外仓”筛选改为“仓库”；删除表格底部两行说明；统计时间保留；不恢复重新载入、保存视图和默认条件标签。用户确认
数据能力按第4节来源规则统计五类库存，按第5节计算各来源单据预计到货时间。用户确认
保留功能商品关键词、类目、销售状态、表格、列设置、五类数量下钻及CSV导出。沿用现有原型
非本次范围报表内创建、审核、修改来源单据；配置时效的独立管理页面；改变调拨在途模块自身算法。范围说明
目标验收五类数量能追溯同仓同商品来源，预计到货能复算；仓库查询和下钻一致。尚无已确认的业务效率数值目标。本版验收定义

02 用户与使用场景

使用角色需要完成的任务权限说明
计划人员查看待审核申购、对应收货仓库和预计到货。角色为场景划分；实际授权由权限方案确认。
采购人员核对未完结采购数量、已上架数量和剩余采购在途。只读报表，不在报表中更改采购状态。
仓储人员核对待发货和计划未出库的库存，追溯最终收货仓库。中转仓与最终收货仓库分别展示。
运营人员结合在库、在途及销量判断库存情况。销量、缺货和可售天数公式未确认前不得据此自动下单。

场景一：按收货仓库查询某商品，点击采购在途，核对采购单、申购单、已上架数和预计到货。场景二：同一批货已发起计划但未出库，仍出现在中转仓在库；完成出库后由调拨在途单据承接，不能重复计入两阶段。

03 业务流程与阶段变化

下图表达报表的阶段归属，不新增业务单据状态。状态转换由来源模块驱动；报表只读取和重新归集。

变化退出或变化的统计进入或变化的统计边界
申购单完成审核对应待审核数量不再计入申购待确认。采购单满足未完结条件时计入采购在途。审核通过与生成采购的具体时序由来源模块提供。
采购货物收货但未上架已上架数量尚未增加，采购在途不扣减。不能仅凭收货事件提前计入中转仓在库。以已上架数量为采购扣减依据。
采购货物完成上架采购在途按本次已上架数量扣减。满足待发货来源条件的数量进入中转。部分上架按行/批次数量处理，不能只按整单状态。
发起计划但未出库待发货来源与计划来源需分配或去重。同一货物继续计入中转仓在库。计划量与待发货量不得重复相加。
完成出库并生成调拨在途已出库数量从中转仓在库退出。调拨模块识别为在途后计入海外在途。部分出库分量转移；事件到达不同步的处理待确认。
调拨完成到仓并同步库存在途余量随来源收货变化。海外仓同步记录提供在库数量。不能用收货事件直接替代仓库在库同步。
撤销、退回、短收或更正报表按来源最新有效记录重算。不在报表内修改业务状态。逆向状态与数量映射列为待确认，不能自行回退到上一阶段。

04 数量来源与仓库归属

以下 R01—R05 为本轮用户确认的主要口径。字段名称为业务含义，实际接口字段和状态编码由研发映射。

规则指标来源与纳入条件数量口径仓库归属
R01申购待确认申购单中处于“待审核”的申购数据。海外仓发货计划模块的待申购数量也需纳入。待审核申购数量；计划模块取待申购数量。若两类来源实际指向同一需求，去重关系见Q02。普通申购取申购单收货仓库；计划模块的待申购量计在计划收货仓库上。
R02采购在途未完结采购单，回溯其关联申购单。采购数量 − 已上架数量。按有效采购明细行计算后归集；单纯收货不扣减。采购单 → 关联申购单 → 申购单收货仓库。
R03中转仓在库待发货列表；已发起发货计划但尚未出库的发货单。合并两类来源的有效数量，同一实物数量只计一次。未出库部分保留在中转仓在库。待发货 / 发货单 → 采购单及申购单 → 最终收货仓库。当前中转仓仅用于解释位置。
R04海外在途调拨在途模块中的在途单据。读取调拨来源的在途余量。示例用已出库−已收货说明；正式字段及取消、丢损映射见Q07。取调拨单据目的仓库。
R05海外仓在库海外仓库存同步数据。使用同步记录的在库数量，不自行以累计入库推算，不直接等同于可售数量。取库存同步记录对应仓库。

4.1 关联、分配与去重

编号要求处理边界
D01保留来源模块、单号、明细行、商品、单位、最终收货仓库及统计批次。不能只用采购单号去重，否则会丢失多行、多SKU或多收货仓库数据。
D02采购行关联多个申购行或多个目的仓时，按实际分配数量归属仓库。分配量合计应与采购行有效剩余量一致；严禁向每个仓库复制整行数量。分配字段待确认。
D03待发货和计划未出库可能描述同一库存，必须保留原库存或业务明细标识。采用互斥来源或数量分配去重，由源模块关系决定；不得默认两类直接相加。
D04关联链断裂、仓库缺失、单位无法映射时，标为统计异常。不得猜测最终仓库，不得把当前中转仓当最终仓。异常是否进入独立报表及总数展示待确认。
D05产品组数量和子SKU数量分层展示。原型采购/中转沿用 floor(各子件数量÷单组用量) 的最小齐套数；BOM版本、共用子件和齐套范围尚未确认。
D06库存阶段反映同一批货的不同位置，不代表所有指标可简单相加。申购为需求，采购在途可能存在未上架与物理阶段重叠；阶段总和字段本版不新增。

4.2 必要来源字段

来源必须能提供的业务字段关联或校验
申购 / 计划来源模块、单号、行号、申购对象、待审核/待申购数量、状态、收货仓库。同需求映射标识；待审核状态编码映射。
采购采购单号/行号、申购关联行、采购数量、已上架数量、完结状态、采购预计交期、目的分配量。校验数量差及目的仓分配；已上架必须区分已收货。
待发货 / 发货单来源单号/行号、采购/申购关联、当前仓、未出库数量、原库存批次、最后上架时间、出库状态。支撑来源间去重；最后上架时间需落实到同一库存批次。
调拨在途调拨单号/行号、商品、目的仓库、在途余量、状态、预计到仓时间、时间更新时间。预计到仓由调拨模块计算，报表仅引用。
海外仓库存仓库、商品映射、单位、在库数量、同步批次/时间、同步结果。需区分库存总量、可售、预占、不可售字段，不默认等价。

05 预计到货时间

每条来源单据分别计算预计到货。预计到货展示在数量下钻明细中；本版不新增一个把所有来源日期合并为单值的主表列。各条明细可有不同到货时间。

规则适用节点公式取值说明
E01申购待审核预计到货 = T + A + B + C + D + ET当前时间；A申购处理时间；B采购处理时效；C采购交期；D仓库作业时间；E在途时效。
E02采购在途预计到货 = P + Dp + EP采购预计交期，为日期/时间；Dp仓库处理时效，为时长。不能将采购交期时长C作为日期P使用。
E03中转仓在库预计到货 = T + [D − (T − L)] + E
等价于 L + D + E		L最后上架时间。当前时间与最后上架时间先求耗时，再扣减仓库作业时间。未擅自增加max(0,剩余时间)。
E04海外在途预计到仓 = 调拨在途单据的预计到仓时间在途时效由调拨在途模块计算；报表不再叠加E。
—海外仓在库已在库，不计算预计到货。保留库存同步时间，不能填造未来到货日期。

5.1 参数定义与边界

参数或条件要求确认情况
T 当前时间同一统计批次使用统一计算时点。统计时间与明细计算时点需可追溯。产品一致性要求；实际调度频率、时区待确认。
A / B / C / D / Dp / E均为时长。参与计算前须统一单位，保留原值和取值来源。具体配置入口、采购/商品/供应商/仓库/线路匹配优先级待确认。
D 与 Dp保留用户在两个公式中的名称，不能直接认定为同一配置字段。是否同一作业时效待确认。
工作日与自然时长未提供工作日、节假日或仓库工作班次规则。原型仅用小时展示样例，不代表生产已采用自然小时。
必要参数或日期缺失预计到货显示“—”，标识具体缺失项，保留数量可查。建议异常处理；不以0替代缺失时效。
剩余作业时间为负按原公式计算会出现负剩余时间，预计到货不随T推进。原型保留原公式并显示负值；是否截断为0、超期改算或仅预警待确认。
预计到货早于统计时间不能悄悄把过去日期改成当前日期。超期状态文案与重估流程待确认；源值和计算依据应保留。
采购预计交期仅有日期不能擅自按当地0点或当天结束时刻计算。日期时间归一规则待确认。
多批次和多次上架每批数量与自身最后上架时间对应，分别计算预计到货。“最后上架”按采购行、库存批次还是商品仓库取值见Q05。
配置变更或调拨预计时间变化保留本次使用的参数/源时间及更新时间。是否重算历史批次、存量记录及生效版本待确认。

以下时间和时效均为演示值，不是已确认的生产时效。以2026-05-19 14:00（UTC+8）为T，按自然小时手算。

场景输入预期计算
申购待审核A24小时、B24小时、C168小时、D48小时、E240小时。T+504小时 = 2026-06-09 14:00。
采购在途P=2026-05-28 14:00，Dp48小时、E240小时。P+288小时 = 2026-06-09 14:00。

06 页面、字段与交互

编号入口 / 功能动作与结果空态 / 失败 / 边界
F01库存 → 全链路库存报表进入展示统计时间、筛选和SKU库存总览；不展示站点和表格底部说明。首次加载、加载失败、无权限见第7节。
F02商品关键词 / 仓库 / 一级类目 / 销售状态输入或选择后点击查询/回车生效；条件取交集。关键词多个词任一包含匹配。无结果保留条件；重置清空四项并重新查询。
F03主表五项库存数量蓝色数量包含0均可点击；抽屉打开同一仓库和商品的来源记录。0数量显示空明细；无来源但有数量属于统计异常，不能显示为正常空态。
F04明细来源单据页签查看单号、关联关系、单位、数量依据、仓库与ETA。中转同时展示当前仓和最终收货仓库。采购/中转子件明细数量单位为件；主表产品组为组，不可直接把子件求和对主表。
F05明细统计口径页签展示该指标来源、仓库归属、数量规则、预计到货公式及换算边界。配置缺失须说明缺失项，避免只给笼统的“计算失败”。
F06关闭抽屉关闭按钮、遮罩、Esc均关闭；恢复列表条件、滚动位置并返回触发控件焦点。抽屉横向表格在内部滚动，关闭不重置查询。
F07复制单号 / 导出明细复制当前来源单据号码；导出当前抽屉来源表，包含预计到货和依据字段。剪贴板权限失败给可恢复提示；浏览器下载发起不保证磁盘保存成功。
F08导出报表导出当前已查询全部结果与可见字段组，附SKU、SPU、名称和仓库。不含站点；接口分页下导出范围不应只限当前页，任务量阈值待确认。
F09列设置供应链库存和销量分析独立显隐，回显当前选择。两组隐藏保留基础字段。当前会话有效；不提供保存视图。
F10销售指标保留3/7/15/近30天销量、日均加权销量、可售天数和缺货数量。现有样例沿用；业务公式待确认，不随本轮来源补充擅自推断。

6.1 筛选字段

字段必填 / 默认数据来源校验与说明
商品关键词否 / 空SKU、SPU、商品名称。去前后空格，大小写不敏感；支持空格及中英文逗号分隔。模糊匹配。批量精确匹配如需增加应另确认。
仓库否 / 全部仓库用户可访问仓库字典。匹配最终收货仓库编码；含义不得因所选指标变化。仓库类型和停用仓库策略待确认。
一级类目否 / 全部类目商品一级类目字典。精确匹配；历史属性还是当前属性待确认。
销售状态否 / 全部状态商品销售状态字典。目前示例在售、预售、清仓；完整枚举和停用状态待确认。

6.2 主表和明细字段

字段组字段取值 / 格式
基础字段商品 / SKU、SPU、商品名称、仓库、一级类目、销售状态。一行对应仓库+商品对象；长名称省略并可查看完整内容。商品列固定。
供应链库存申购待确认、采购在途、中转仓在库、海外在途、海外仓在库。按R01—R05；数量单位沿用产品组/单SKU约定，单位映射待确认。

采购数量依据采购数量、已上架数量、剩余采购在途、单组用量。显示单位；采购行与申购行关联可追溯。

来源溯源来源模块、单据/行标识、申购/采购关联、统计批次。不能只展示反推出来的单号。正式接口字段和链接入口待对接。

07 权限、异常与数据处理

本节为待评审的实现要求。未获得用户确认的角色授权、数量修正和调度策略不写成既定业务规则。

场景要求 / 建议恢复及待确认项
权限页面查看、仓库数据范围、来源单据查看、报表导出、明细导出分别鉴权；后端强制执行。角色到权限的实际映射待确认。不能因为去掉站点就扩大原数据授权范围。
无权限页面无权则显示无权限结果；无导出权则隐藏或禁用导出并说明。隐藏/禁用选择按现有权限体系确认。
加载 / 失败请求中给加载反馈；失败保留筛选输入、展示原因和重试入口。不得把失败展示为空数据，也不能把上次结果当最新结果。
部分来源失败标识失败来源和该批次不完整，保留可追溯时间。是否允许查看旧完整批次及是否允许导出待确认。

数量关联丢失关联链无法确定目的仓库时，不归入猜测仓库。补链、异常归集位置及对主表提示方式待确认。
ETA缺失 / 逾期缺数据不填0时效；过期源日期不自动改成今天。缺失原因和超期重估见第5节。
取消 / 退回 / 更正报表只读，按来源有效数据重算。取消与完结状态枚举、软删记录、逆向数量抵扣待确认。
历史数据上线前校验未完结采购申购关联、最终仓库、已上架数量、批次及时效参数。迁移范围、可回溯起点、历史批次重算及回滚方案待定。不得用无来源默认值掩盖缺口。
