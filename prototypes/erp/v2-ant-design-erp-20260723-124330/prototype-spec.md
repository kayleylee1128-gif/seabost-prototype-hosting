# 其他出库 - 返修出库 v2 原型说明

## 来源与范围

- 来源页面：现有“其他出库 / 返修出库”线上原型。
- 本版本为独立重设计版本，不覆盖原型源文件和原在线链接。
- 保留原业务范围：返修出库列表、状态筛选、物流绑定、详情查看、返修方案编辑、赔款/抵扣账单/返修换货信息维护。

## 页面来源映射

| 页面区域 | 业务目的 | 组件映射 |
|---|---|---|
| 顶部壳层 | 模块切换、用户身份、全局工具 | `ErpShell` |
| 业务 Tab / 状态 Tab | 切换出库类型和单据状态 | `Tabs` |
| 筛选区 | 按仓库、单号、创建人、审核/出库状态、时间查询 | `QueryFilterBar` + 自定义 `Select` |
| 结果区 | 查看返修出库记录并执行行级操作 | `DataTablePanel` + `Tag` + `Pagination` |
| 详情 | 查看出库仓库、供应商、返修方案、收件信息和 SKU | `DetailDrawer` |
| 返修方案 | 编辑返修、赔款、抵扣账单、返修换货字段 | `EditDrawer / Modal` + `Form` |
| 反馈 | 保存、绑定物流、打开日志后的结果提示 | `Message / Notification` |

## v2 UI 设计契约

- 默认遵循 `shared-references/ant-design-ui-guidelines.md` 的 Ant Design B 端基线。
- 页面以表格和筛选为视觉主轴，卡片只负责分组，不使用营销型大卡片、渐变或玻璃效果。
- 所有下拉入口使用自定义 Ant-style Select，不使用浏览器原生 `<select>`。
- 详情与编辑优先留在当前列表上下文内；高风险取消动作需要明确反馈。
- 颜色、字号、间距、圆角、阴影统一消费 `../../ui-library/tokens.css`。
