# 公共配置（字典管理）模块原型说明

## 页面信息

- 页面名称：公共配置 / 字典管理
- 原型等级：L2 交互原型初稿
- 适用角色：企业管理员、系统管理员
- 用户入口：系统设置 → 公共配置

## 页面来源映射

| 可见元素 | 来源 | 说明 |
|---|---|---|
| 公共配置列表 | 用户确认“公共配置模块” | 管理自定义配置对象 |
| 新建配置 | 用户确认“可以自定义加字段” | 创建配置基本信息后进入设计器 |
| 字段定义 | 用户确认“配置项下面可以自定义字段” | 定义接口返回字段的名称、编码与类型 |
| 配置数据 | 用户确认“字段值以及对应的具体值” | 按字段结构维护业务可调用的具体数据 |
| 批发单定义案例 | 用户确认“公共配置中列个批发单标识案例单据数据” | 展示平台、店铺、SKU 数量、订单总数量、是否自动申购和缺货百分比 |
| 配置启停 | 用户确认“操作栏增加启用和禁用操作” | 列表直接启用；禁用前确认下游影响 |
| 更新信息 | 用户确认“最后更新显示年月日时分秒及更新人” | 列表和详情同步展示并在保存后刷新 |
| 编辑基本信息 | 用户确认“点击编辑基本信息需要交互” | 抽屉回填名称、说明及调用模块，保存后回显 |
| 编辑字段 | 用户确认“字段定义点击编辑需要交互” | 抽屉回填字段；已发布编码和类型锁定 |
| 发布与版本 | 通用配置治理保守假设 | 防止已引用结构被直接覆盖 |
| 原型标注 | 工作室 AGENTS.md 强制要求 | 默认开启，可关闭恢复纯净原型 |

## 核心规则

1. 数据模型为“配置项 → 字段定义 → 配置数据”。
2. 配置编码用于业务模块定位字典；字段编码作为返回对象的属性名。
3. 字段至少包含名称、编码和类型，可补充必填、默认值和说明。
4. 配置数据每行代表一条业务可选值，并按字段定义填写具体值。
5. 被调用的配置或字段不能直接停用、删除，需先确认下游影响。
6. “批发单定义”示例数据：Amazon / 全部店铺 / SKU 数量 50 / 订单总数量 100 / 自动申购“是” / 缺货百分比 20%。
7. 配置列表操作栏提供“进入配置”和“启用/禁用”；禁用必须确认影响，启用后立即恢复生效。
8. 最后更新时间统一采用 `YYYY-MM-DD HH:mm:ss`，并单独展示更新人。
9. 配置基本信息保存后刷新列表、详情、变更记录、更新时间和更新人。
10. 已发布字段编辑时，字段编码和数据类型不可修改；字段名称、必填、默认值和说明可修改。
