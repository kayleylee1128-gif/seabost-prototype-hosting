批发单分批来货需求文档

版本：V1.9（评审稿） · 日期：2026-10-16
涉及系统：仓库系统（WMS）、订单系统（OMS）

1. 需求目标

支持批发采购单分批到货：质检时按仓库规则分配批发、小包数量；上架后按实际数量回传订单系统并自动预占。采购单全部上架且完结后，订单未满足的需求使用普通小包可用库存补足。

2. 质检分配规则

仓库可独立配置以下规则。按采购单明细、SKU、仓库分别计算，分批到货使用各类型的剩余待收数量。

  • 批发剩余待收 = 批发采购需求 − 此前累计已确认的批发分配数量。
  • 小包剩余待收 = 小包采购需求 − 此前累计已确认的小包分配数量。
规则批发分配数量小包分配数量
规则1：批发优先min（本次实收，批发剩余待收）本次实收 − 本次批发分配
规则2：普通小包优先本次实收 − 本次小包分配min（本次实收，小包剩余待收）

规则2先满足普通小包需求，再将剩余数量分配给批发。

数量不得为负，两类分配之和必须等于本次实收，且不得超过各自剩余需求。超收需按确认后的超收流程处理，不自动归入某类库存。

质检页面

页面新增显示“本次分配（批发／小包）”。修改实收数量时，按仓库配置规则自动重算并更新两类分配数量。

3. 贴标数量录入

页面顶部新增“贴标数量”输入框，列表新增采购单列、操作栏及“打印条码”操作，删除“批发数量”列。

  • 扫描SKU条码：快速定位到对应SKU行，输入贴标总数量，由前端按当前分配规则及各明细待贴标数量分摊，更新各行贴标数量，分摊合计等于输入总量。
  • 扫描批发标签：自动定位到对应采购单的SKU行，现场输入数量；输入数量不为0且与现场分配数量不一致时，弹出“需要重打批发标签”，支持手动关闭或3秒后自动关闭。输入0不触发此提示。
  • 批发SKU与普通SKU分行展示，各批发单明细独立显示并保留BO单号关联；普通备货单SKU按“包裹＋SKU”维度合并为一行。
  • 操作栏支持打印条码，并支持在数量不一致时重新打印批发标签。

4. 上架与回传

质检分配是计划结果，最终库存归属以实际货位类型及上架数量为准，允许计划与实际上架不一致。

  • 按批次记录实际批发、小包上架数量，并展示与计划分配的差异。
  • 每次上架成功后，将本次实际增量回传订单系统，关联采购明细、SKU、仓库、批次及上架明细。
  • 订单系统按实际批发可用库存自动预占绑定批发订单，预占不超过订单未满足需求；小包上架数量计入普通库存。
  • 回传失败支持重试，重复回传不得重复增加库存或预占；状态先到时，等待上架数据同步完整后再执行最终校验。

批发标签打印：货位推荐

打印批发标签时，按货位最大货品数及剩余体积计算推荐批发货位，不单独查询空货位。按BO订单维度优先推荐该订单已有产品上架的货位；不满足推荐条件时，推荐其他满足条件的批发货位，同一批发货物允许分布在多个货位。

批发货位上架限制

上架到批发货位时，仅按货位配置的最大货品数限制，不增加剩余体积、混放或同一订单只能使用一个货位等限制。剩余体积用于打印标签时推荐，不作为实际上架的阻断条件；允许同一批发货物上架到多个货位。

库存查询：占用单据标签

订单系统 → 库存查询 → 占用单据查询，在平台单号旁按占用订单类型显示标签：批发订单显示“批”，定制订单显示“制”，普通订单不显示标签。

5. 订单库存校验

绑定采购单同时满足“全部已上架、已完结”，且上架数据同步完整后，执行补足校验：

  1. 根据实际批发上架数量及订单已有预占结果，先满足批发库存可保障的需求。
  2. 剩余需求 = 订单有效需求 − 该订单已有效预占数量，校验普通小包可用库存并预占。
  3. 库存满足后流转单据；不足时保持待库存状态，显示缺口。

可用库存沿用现有口径，扣除冻结及其他订单占用。重复校验不得重复占用或流转，并发预占不得超占。采购单未满足上述条件时，本需求暂不触发普通库存补足。

批发订单处理：已上架数量

订单系统 → 订单列表 → 批发订单处理页面，在采购单号右侧新增只读列“已上架”。按当前订单、SKU及绑定采购单关联的上架记录，显示累计实际上架数量；分批上架累计展示，关联多个采购单时汇总对应记录，避免重复统计。未绑定采购单或尚未上架时显示0，上架数据回传后更新。

6. 业务案例

采购需求200，其中批发120、小包80；使用规则2，绑定批发订单需求120。

批次本次实收质检分配：批发／小包实际上架：批发／小包
第一次15070／8070／80
第二次5050／00／50
合计200120／8070／130

第一次先满足小包80，剩余70分配给批发并完成批发预占。第二次小包计划已满足，质检分配批发50，但实际全部上普通货位。

采购单全部上架且完结后，订单已预占批发70，剩余50校验并预占普通库存。普通可用库存充足则流转；若无其他占用或冻结，普通库存130扣除补占50后剩余80。

7. 仓库移库与解绑通知

货位属性：统一批发

仓库货位属性保留一个“批发”选项，移除“定制”选项。货位新增、编辑及属性筛选中的选项同步调整；现有“定制”属性货位统一归入“批发”，使用同一套批发货位逻辑。普通等其他货位属性沿用现有规则。该调整仅针对货位属性，订单类型及占用单据“制”标签仍按订单类型展示。

理货移库：批发转普通

仓库系统 → 移库任务模块 → 理货移库，新增类型“批发转普通”。针对位于批发货位、且未绑定批发单的库存，生成该类型移库任务，移至正常货位属性的货位。

新库位按以下顺序推荐：

  1. 查找符合现有入库条件、正常货位属性且已有库存的候选货位，按现有容量口径判断能否容纳本次移库数量；放得下则推荐该货位。
  2. 无符合条件且放得下的已有库存货位时，推荐符合条件的空货位。
  3. 无可用货位时，提示“暂无可推荐货位”，保留任务供后续处理。

候选货位沿用现有SKU混放、库存属性及容量校验规则。任务记录源货位、推荐新货位、SKU、移库数量及类型；执行时复核库存未绑定批发单、源库存和目标容量，避免库存变化后错误移库。任务完成后按实际移库结果更新普通库存归属。

上架后解绑：仓库消息通知

库存已上架后，执行解绑批发单操作，解绑成功时向对应仓库配置的通知人发送消息；解绑失败不发送成功通知。

仓库默认通知人
东莞仓袁锋
东莞2仓赵新波

公共配置模块新增“上架后解绑仓库通知人”，按仓库维护通知人。通知包含仓库、BO单号、SKU、解绑数量、当前货位、操作人及操作时间，便于仓库识别需处理的库存。通知失败记录状态并支持重试，同一次解绑不得重复发送；通知失败不回滚已成功的解绑。

上架后解绑成功，针对仍在批发货位且已无批发单绑定的解绑库存，自动生成“批发转普通”移库任务，将库存从批发货位移至普通货位，并按本节规则推荐目标货位。同一次解绑不得重复生成任务；涉及多个源货位时记录各源货位及对应数量。
